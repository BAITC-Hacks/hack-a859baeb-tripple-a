# Запуск AlemScope

Требования: Python 3.11+ и Node.js 20+.

1. Распакуйте архив и откройте папку AlemScope в терминале.
2. Вставьте ваш действующий секретный ключ OpenAI в файл .env:

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4.1-mini
DATABASE_PATH=data/alemscope.sqlite3
```

Файл .env уже включён в архив и исключён из Git. Не заменяйте его после заполнения.

## Установка зависимостей

Из папки AlemScope (macOS/Linux):

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.lock.txt
cd frontend
npm ci
cd ..
```

## Первый терминал — backend

Из папки AlemScope:

```bash
source .venv/bin/activate
python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

## Второй терминал — frontend

Из папки AlemScope:

```bash
cd frontend
npm run dev
```

Откройте http://127.0.0.1:5173.
Выберите New analysis → OpenAI semantic analysis, загрузите документы BEFORE и AFTER и запустите анализ.
После изменения .env перезапустите backend и обновите страницу.
При ошибке address already in use остановите старый сервер через Ctrl+C в его терминале.
Для Windows используйте активацию .venv\Scripts\Activate.ps1 вместо source .venv/bin/activate.

Кнопка Explore the supplied documents запускает локальный демонстрационный анализ без OpenAI.
Для семантического анализа образцов загрузите fixtures/before.pdf и fixtures/after.pdf через New analysis и выберите OpenAI semantic analysis.

## Проверка

```bash
python -m pytest backend/tests -q
python -m ruff check backend
cd frontend
npm run typecheck
npm run build
```

В архиве есть весь исходный код, обе тестовые PDF, тесты, README и архитектурная документация.
Зависимости устанавливаются командами выше. Пользовательские загрузки, локальная база, старые ключи и виртуальное окружение не включены.
Все выводы анализа требуют проверки человеком. Нет OCR и авторизации пользователей; прототип предназначен для localhost.
