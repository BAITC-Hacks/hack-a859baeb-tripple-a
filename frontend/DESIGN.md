# AlemScope visual direction

A decision workspace for employees comparing responsibilities of a reorganized institution. Evidence is primary content, so comparative rows and source fragments receive more space than decorative charts.

Palette: ink #172f3b, sidebar #152b37, canvas #f3f6f7, paper #ffffff, teal #0f766e, caution #a76415. Blue identifies before; teal identifies after. Typography: Avenir Next with Segoe UI and system sans-serif fallbacks. Left-aligned page titles, sentence case labels, tabular numerals.

Layout: persistent compact navigation, broad document workspace, paired before/after lanes, horizontal result tabs, evidence expanded in context.

```
[nav] [workspace / analysis]                      [service]
      [title and purpose]                       [action]
      [before document set]  ->  [after document set]
      [overview | organization | functions | findings | report]
      [before responsibility | after responsibility | source]
```

Review against the brief: a generic SaaS grid would hide the comparison. Use broad comparative tables and inline evidence drawers; cards are reserved for distinct metrics and upload sets. A document-to-structure visual explains the empty workflow without fabricated analytics. Every conclusion requires human review; local mode explicitly states lexical review, without implying semantic AI.
